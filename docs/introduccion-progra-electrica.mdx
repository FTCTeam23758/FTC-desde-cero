En esta área, nos encargamos de darle vida al robot, a través de la electrónica y la programación. Utilizamos sensores, motores y código para darle ordenes a nuestro robot y así lograr los objetivos que queremos cumplir con este.

## ¿Qué es la programación?
Programar es dar indicaciones, como si escribieras una receta de un pastel. En este caso, utilizamos una computadora para escribir instrucciones a nuestro robot.

En un robot de FTC, vamos a utilizar estos dos compoentes para poder darle indicaciones a nuestro robot.
- **Control Hub** - Es como el cerebro de nuestro robot. Es el componente que nos permite controlar motores y sensores, y al que le damos indicaciones desde la computadora.
- **Driver Hub** - Un dispositivo que nos permite controlar los robots a distancia, monitorear información, y escoger los programas.

![Control Hub](/img/controldrivehub.png)

## ¿Cómo programar un robot de FTC?
Para programar nuestros robot, utilizamos el Starter Developer Kit de FTC, una plataforma de software que nos permite leer y escribir datos como las lecturas de un sensor, o prender y apagar un motor, desde nuestra Control Hub, utilizando Java como lenguaje de programación.

Desde la computadora, le damos indicaciones a nuestra Control Hub, y podemos tomar decisiones como controlar motores, servos y sensores. A la lista de indicaciones que le damos a nuestro robot, se le llama OpMode.
