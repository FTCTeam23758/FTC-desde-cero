Para poder programar nuestro robot, primero tenemos que tener un entorno de desarrollo donde escribir código, es decir, la aplicación dónde escribiremos nuestros programas y los subiremos a nuestro robot.
Para hacer esto, utilizaremos **Android Studio**, la mejor opción para programar en FTC.

## Pasos para instalar Android Studio y poder utilizarlo en FTC
- **Instala la versión más actual de Java**
- **Descarga la versión más actual de Android Studio desde su sitio oficial siguiendo las indicaciones que te pide.**
